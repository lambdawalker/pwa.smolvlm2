Made for your phone. Designed for your privacy.

Photos are resized locally and never uploaded. Model files download from Hugging Face. No account, analytics, or API key. Descriptions are in English.

Requires WebGPU: a compatible Android browser or Safari on iOS 26+. Older devices may run out of memory. Keep this app open while it works.

For offline use, finish a description online first so all model files are cached. Browser storage can be cleared or evicted; offline access is not guaranteed. On iPhone, use Share → Add to Home Screen to install.
